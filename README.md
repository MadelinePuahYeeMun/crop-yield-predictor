# District-Level Crop Yield Prediction using Machine Learning

## Project Overview

This project focuses on predicting district-level crop production using machine learning techniques by combining agricultural production, cultivated area, and weather-related datasets.

The project demonstrates a complete machine learning workflow including:

* Data preprocessing
* Dataset merging
* Exploratory Data Analysis (EDA)
* Feature engineering
* Model training
* Hyperparameter tuning
* Model evaluation

The main objective of the project is to analyze factors affecting crop production and build predictive models for agricultural yield forecasting.

---

## Objectives

* Predict district-level crop production using machine learning
* Analyze relationships between weather conditions and crop yield
* Practice real-world data preprocessing and feature engineering
* Improve understanding of model training and optimization workflows

---

## Dataset

Datasets used in this project include:

* Crop District Production Dataset
* Crop District Area Dataset
* Weather Dataset

The datasets were merged to create a unified machine learning dataset containing agricultural and environmental features.
